# 終局報酬と評価指標

実装日: 2026-10-13。報酬版: `saichugen-2003-table2-v1`。
根拠は[副田・田中2003](https://ipsj.ixsq.nii.ac.jp/record/58572/files/IPSJ-GI03010005.pdf)紙面32 §3.2(5)–(6)、紙面33表2。2021年論文のルール節ではこの表を省略しており、廃止の根拠にはしません。原案との完全一致は未確認です。今回はプロジェクトの明示的な採用として実装しました。

## 累計得点G・勝者W・報酬U

既存エンジンが最終累計得点Gと中位勝者Wを確定した後、純粋関数game/rewards.pyのterminal_rewards(W)でUを計算します。

| 勝者人数 | 各勝者 | 各敗者 |
| --- | ---: | ---: |
| 1 | +2 | −1 |
| 2 | +1 | −2 |
| 3 | 0 | 0（敗者なし） |

出力は座席0・1・2順の3要素で、合計は必ず0です。空集合、重複、不正座席、boolや実数の座席番号は拒否します。乱数もGame参照も使用しません。Gへの加算やWの再判定をしません。engine.py・カード比較・勝者判定・基本戦略・配札と戦略乱数は変更していません。

通常対戦APIでは終了前のterminal_rewardsはnull、終了後は3要素配列です。履歴を表示していても終局結果パネルは、その試合の最終結果と明示して表示します。StrategyのObservationにはUを追加しません。既存の判断目標はそのままです。

## 実験指標

対象戦略の参加席を1標本とします。同じ戦略が複数席で出る場合も席を混同せず集計します。座席回転後も、その結果行のstrategiesと同じ添字の報酬を使います。

- 勝率: 対象席がWに含まれるゲームの割合。既存定義を維持。
- sole_win_rate: 対象席が唯一の勝者である割合。
- joint_win_rate: 対象席が2人以上の勝者の一員である割合。全員勝利も含む。
- average_score: 最終累計得点Gの算術平均。
- average_terminal_reward: 算出可能な終局報酬Uの算術平均。

完全な勝者記録では勝率＝単独勝利率＋共同勝利率です。全員勝利は勝率1、共同勝利率1ですが報酬0です。勝率最大化と期待報酬最大化は同じ目的ではありません。平均累計得点と平均終局報酬は別ラベル・別の比較グラフとして扱います。

## SQLiteと旧JSONの互換性

既存experimentsテーブルはpayloadのJSON保存です。テーブル再作成・削除・UPDATEは行いません。ExperimentStoreは従来どおり元JSONを読み書きし、実験GET応答ではexperiments/evaluation.pyの読み取りアダプターが追加指標を補います。保存済みJSONを変更せず、古いsummaryの従来指標も保持します。

新しい結果はresult_schema_version=2、reward_versionと各行のterminal_rewards・reward_sourceを保存します。ルール版は従来のgpcc-public-secondary-v1のままです。報酬が追加されたことを別のゲームルールとして扱いません。CLI結果にも報酬版と各席の報酬を記録します。

旧結果は、既知のルール版または明示的な対応報酬版があり、勝者情報が有効なら読み込み時に再計算します。元のGは上書きしません。

| reward_source | 意味 |
| --- | --- |
| recorded | 対応する版で保存され、勝者情報とも整合する報酬 |
| derived_from_winners | 旧勝者情報から読み取り時に補完 |
| unknown | 勝者欠落・不正、未知の版、不整合な保存報酬など |

対応版で保存された配列でも勝者情報と一致しなければ不明とします。不明を0にしません。reward_gamesとreward_unknown_games、reward_sourcesを返し、平均Uは算出可能分だけで求めます。0件ならnullです。勝者欠落が混ざる場合、単独・共同勝利率はnullにします。図鑑ではルール・情報条件・戦略版・相手・設定に加えて報酬版も分けます。過去の条件不足実験を自動で別条件へ移しません。

新旧差は実験のreward_compatibilityと、図鑑の記録済み・補完・不明件数で確認できます。将来の報酬版は現在の報酬平均へ無条件に合算しません。元の履歴を保つ方針のため、一括書き戻し移行や保存結果閲覧UIの新設は今回行いません。

## 分岐シミュレーション

従来どおり試行番号ごとの世界と席別初期乱数を候補間で共有し、すべてのゲームを同じ方法で終局まで進めます。終了後の集計だけにUを追加するので、選択・勝率・G・サンプリング・状態複製・停止経路は変わりません。

候補ごとに平均U、単独・共同勝利率を表示します。各候補対A/Bでは同一試行iの報酬差D_i=U_Ai−U_Biを作り、次を返します。

- average_terminal_reward_difference: Dの平均。
- reward_difference_ci95: 平均±1.96×標本標準偏差/√Nの正規近似区間（報酬差の範囲−4〜+4で切る）。
- reward_difference_samples: 対応する試行組数。
- reward_difference_zero_variance: 2試行以上で全標本差が等しいか。

独立した区間同士の引き算ではありません。1試行では区間をnullとし、分散0では平均と同じ端点になりますが、画面では不確実性ゼロの保証ではないと表示します。少数試行・モデルの誤り・共通乱数の限界に関する既存の注意は継続します。停止・時間切れ・失敗は従来どおり部分統計を返しません。

分岐結果schema_version=2とreward_versionを記録します。完了結果のメモリ保持、同時1件、最大1000試行・10000分岐、60秒の協調停止という制限はそのままです。

## 検証と今後

表の全7勝者集合、座席対応・ゼロ和、不正入力、G/Wと選択の回帰、旧SQLite非破壊補完、不明値、座席回転、対応差と少数試行を自動検証します。追加処理は終局1回の3席計算と標本の線形集計です。戦略判断やゲームループへ新しい探索・乱数処理を入れません。

報酬に合わせた新戦略の追加、報酬の分布・標準誤差のより詳細な可視化、原案全文の照合は今後の候補です。現在の戦略を自動で別の目的関数へ変更するものではありません。
