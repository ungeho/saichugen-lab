# 観測と推論の境界

初期版は `imperfect`。これはデフォルトの遊び方であり、将来の完全情報・カスタム情報モードを禁止するものではない。モードは結果に記録する。

## Strategyへの入力

不変のObservationと戦略専用の乱数源だけを渡す。

| 項目 | 内容 |
| --- | --- |
| player | 本人の座席0〜2 |
| hand / legal_actions | 本人の手札。終局後の合法手は空 |
| history | 公開済み全ターンの座席別カード・勝者・得点 |
| round_scores / game_scores | 現在のラウンド得点とゲーム得点 |
| turn / hand_sizes | 解決済みターン数と全員の残り枚数 |
| unseen_cards | 52枚から自分の手札と公開札を除いた集合 |
| actions_by(player) | 指定プレイヤーの公開行動列 |

相手の手札、余り札、保留中の提出札、エンジン参照、配札シードは渡さない。シードから手札を再現できるため、シードは実験管理側で保持する。

全員の観測を選択前に確保してから決定を集め、一括解決する。未知札は初期35枚、tターン後は35−2t枚。終局時は相手各2枚と余り1枚の5枚。

## 手札候補

UniformSamplerは未知札を各相手の残り枚数と余り1枚に重複なく割り当てる。行動傾向を考慮しない一様事前分布であり、真の手札ではない。BeliefSampler境界を使い、将来ベイズ推論・Opponent Modeling・Particle Filter・ISMCTSの候補生成を追加できる。

## 完全情報を使う分析

research.replayは初期配置・余り札・行動列を保存し、合法性を再検証して再現する。research.evaluationは相手手札への所属確率と実際の手札のBrier誤差を評価する。通常の対戦APIにこれらの取得経路は設けない。

現在は評価関数まで。精度の時間推移と推論あり・なしの勝率比較は将来追加する。完全情報・カスタムモードは、観測作成と実験条件を拡張する形を想定する。任意コードを隔離するサンドボックスなど過剰な防御は初期版に導入しない。
