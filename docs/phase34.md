# Phase 34：Stopping Generalization & Budget Horizon Lab

## 1. 研究目的

固定した停止規則が、予算上限を伸ばした場合に計算を減らし、独立評価報酬をどの程度保つかを調べる。早期停止0も有効な結果。Fixedを不利にせず、少数配札で優位性を断定しない。

## 2. Phase 33からの変更

Phase 33は `ff14b33659a8e8379460c8fddc5443b8d7b7e374` として通常commit・push済み。Phase 34は未ステージ・未commit・未pushで残す。ゲーム、戦略、Rollout、終局報酬、停止判定の実装は変更していない。既存のworker、SQLite、配札予約、三標本、JSON原文出力を再利用する。

## 3. 固定停止規則

初期16世界・追加16世界。Gapは最上位と次点の対応報酬差が0.5を厳密に超えたとき。Uncertaintyは全競合への対応差が `2 × SE + 0.05` を厳密に超えたとき。SEが未提供なら停止しない。Fixedは常に上限まで進む。報酬同値はrank昇順、次にsuit昇順。これはカードのゲーム内強弱ではなく探索のタイブレーク。停止用SEは逐次有効区間ではない。

既存 `adaptive_analysis.stopping / ranked / gap_statistics` を呼び、Phase 32版のASTとの一致とログ有無の選択一致をテストする。規則Hash: `b774337d8b3525d0f254d7dc9611e43403fc8db77d2001b2ff962806e4126fe4`。共通世界生成は `rollout_trial` を変更せず使用する。

## 4. Budget Horizon設計

16 / 32 / 64 / 128 / 256世界。主比較はデータ取得前に128世界のGap − Fixedと固定し、独立評価報酬差・派生対局差の2アウトカムをモデル別に記述。他予算・Uncertainty・層別は副次。128を含めないPlanでは主比較は未評価。反復や上限を独立配札として数えない。

## 5. ネストした世界列

局面Hashからpolicy domain seed、反復seedを導出し、既存Fixedを最大上限まで1回だけ実行する。上限16〜256はすべてこの経路の接頭辞を使う。候補の列挙順に依存せず、世界内で全合法手を評価する。各モデルは自分の観測情報しか受け取らない。未公開手札は本人の手札・公開履歴・残り枚数から一様割当し、実対戦の隠れ手札を評価に使わない。行動選択確率を用いた高度な事後分布ではない。

## 6. 停止時点再構成

各予算の最初の16世界から順に既存停止関数を適用し、最初に成立したチェックポイントで停止する。上限まで未成立なら上限のカードを選ぶ。候補評価・カード・タイブレーク・理由・コストが直接実行と一致することを全5上限でテストする。接頭辞不足は拒否。再構成は標本や乱数を追加しない。

## 7. 停止機会と実際の停止

`first_condition_worlds` はその上限内の最初の条件成立。`condition_before_cap` は上限より前の成立。`actual_stop_worlds` はその方式を実行した場合の停止世界数。`early_stop` は停止世界数 < 上限。`max_budget_reached` は停止世界数 = 上限。上限ちょうどの条件成立はraw理由を残すが分類はmax_worldsであり計算削減ではない。Fixedはcompleted_fixed_budget。16世界では早期停止率0。

`first_condition_full_research_path` は最大研究経路での初成立を記述する研究専用情報。実戦時には未観測のチェックポイントを判断へ戻さない。実際の最大経路と再構成した各方式の停止ログはroleとフィールドを分ける。

## 8. 未使用配札の管理

検証区分1000000〜1999999のみ。Phase 33の1900000/1900001は設定時点で拒否。既存SQLiteの予約・実験・Planとの実配札Hash重複も拒否する。最終評価区分は使わない。5収集元（Random / Heuristic / ScoreAware / Zigzag / Reverse Zigzag）の到達可能な局面を収集。選択は実配札使用数を最優先、進行時点、得点層、収集元使用数を順に均し、局面Hashで固定タイブレーク。結果には依存しない。1配札最低1局面の枠を必須にする。

Hash・事前局面一覧・全20得点層×時点の収集／計画／評価件数を保存。キャンセル時は未評価局面を欠測として残す。観測情報は自身の手札・公開履歴等のみ。実配札Hashは識別子であって相手の手札を戦略に渡すものではない。

## 9. Fixedとの対応比較

局面・モデル・反復・上限が同じFixedとの差を比較する。全上限／方式で独立最終評価の同じカード別結果表を共有し、比較件数に応じて実標本数を水増ししない。反復平均→局面平均→実配札平均で等重みに集約。予算、モデル、得点層を混ぜない。

配札単位の有界Hoeffding＋Bonferroni（alpha .05、比較数の保守的上限10000）。独立配札10未満は報酬差・コスト差の区間を提供せず理由を残す。停止率の参考区間は配札平均に対する[0,1]境界。2配札では全て[0,1]。同じカードの差が0でも一般的な同等性の証拠ではない。任意の統計停止・有利な停止局面だけの主分析を行わない。

## 10. 停止後の選択変化

早期停止した札と同上限Fixed札を同じ独立最終標本で比較。さらに最大研究経路の後続チェックポイントでFixed札が切り替わった世界数と前後カードを保存する。上限を超えた研究経路の変化も含むため、範囲を明示する。停止後の経路を見て選択・閾値を修正しない。

## 11. 独立参照とRegret

Policy Selection / Reference Selection / Final Evaluationは異なるdomain-derived seed。参照と最終標本は上限／反復間で共有する研究オーバーヘッド。Self-Middleは同上限・モデル・反復のFixed接頭辞内で直近中位率が最大の札。符号付き推定Regret = 独立最終標本上の参照札報酬 − 選択札報酬。負値を切り上げない。有限標本参照札も256世界Fixed札も真の最適手ではない。

## 12. 計算コスト

`counterfactual_policy_cost` はその方式・上限を独立実行した場合の世界数、候補数×世界数の派生対局数、派生対局×残りターンの手番数。秒数は未計測のためnull。最大経路の経過時間を接頭辞へ配分しない。

`actual_research_compute_cost` は実際の最大Fixed経路＋参照＋最終評価。selection_costも最大経路の実計算コストであって再構成した全方式の総和ではない。収集10対局・150手番は別計上。中断時はexecution_costの開始／完了対局／完了手番を参照（途中1対局の部分手番は未計測）。予算超過・時間超過・キャンセルは未完了扱いで集約を提供しない。

最大80,000派生対局、120秒、4配札、8局面、5反復。登録前に候補枚数・最大上限・モデル数・反復数・参照／最終標本から上限を見積もり、設定の対局上限と上側時間見積もりを超えるPlanは拒否する。時間の見積もり係数は未校正で、実行中も時間制限を確認する。

### 停止機会・理由・カード

12本の最大研究経路（2局面×3モデル×2反復）から180方式条件を再構成した。この180を独立サンプルとは数えない。Fixed完了60、最大到達103、早期停止17。最大到達には条件が上限ちょうどで成立した場合を含む。

初成立は最終ラウンド同点局面だけで、Random反復1のGapは16、ScoreAware反復0のGapは32／Uncertaintyは64、ScoreAware反復1のGap／Uncertaintyは16。Heuristicと厳密中間の直前局面では256まで両条件とも未成立。

Random反復1は16世界で♦Qを選んで停止し、研究用の160世界チェックポイントでFixedが♥2へ切り替わった。上限128までは両方式♦Qで同じ、上限256ではFixed♥2との独立評価差は+0.375。この1経路が全配札・反復平均の+0.09375となる。偶然・参照モデル依存・小標本誤差を排除できず、Gapが優れるとは結論しない。ScoreAwareの早期停止札は♦Qで対応Fixed札と同じ、停止後の切り替えなし。
