# Phase 28：Middle-Position Stratification Lab

## 目的と基準版

## 厳密中間と層別条件

自己得点S、相手得点A/Bについて `min(A,B) < S < max(A,B)`。同点を含む得点配置は別層とし、厳密中間に含めない。その他は最高・最低得点の対照層とする。

| 指標 | 定義 |
| --- | --- |
| upper_gap | max(A,B) − S |
| lower_gap | S − min(A,B) |
| gap_balance | upper_gap − lower_gap |
| gap_min | min(upper_gap, lower_gap) |
| gap_total | upper_gap + lower_gap |

厳密中間では上下差は正。対照層でも同じ式を保存するが、負の差を「中間からの距離」と解釈しない。

初期分類版は `strict-middle-v1`。Phase 27の近似再現データで確認した厳密中間の上下差は1〜18点、中央値6点だった。この参考分布には同一配札の反復が含まれ、母集団の分布推定ではない。Phase 28実験前に小差5点以下、大差10点以上、均衡許容幅0点を固定した。

| 層・タグ | 条件 |
| --- | --- |
| 均衡 | abs(upper_gap − lower_gap) ≤ balance_tolerance（既定0） |
| 上側接近 | upper_gap < lower_gap、かつ均衡ではない |
| 下側接近 | lower_gap < upper_gap、かつ均衡ではない |
| 上下差が等しい | upper_gap = lower_gap（厳密な等号を別保存） |
| 両側とも小差 | max(upper_gap, lower_gap) ≤ small（既定5） |
| 両側とも大差 | min(upper_gap, lower_gap) ≥ large（既定10） |

小差・大差タグは接近型と重複する。6〜9点や、一方が小差で他方が大差の局面を無理に両側小差・両側大差に分類しない。閾値、許容幅、版は登録Hashに含め、登録後に変更できない。

## 局面収集と到達可能性

同じ開発用配札をRandom、Heuristic、ScoreAware、Zigzag、Reverse Zigzagで進行させる。各軌跡の3席すべてを観測する。収集元の3席は同じ戦略であり、異なる相手構成の試験ではない。

既存Gameの合法手から15手を実行し、指定した判断直前だけを記録する。人工的な得点・手札を注入しない。テストでは公開履歴を元の配札から再実行し、観測が一致することを確認する。

内部turnは0始まり。既定収集時点は3・6・9・11・12・13・14。序盤はturn<5、中盤は5〜10、最終ラウンド直前は11（第4ラウンド最終手の直前）、開始は12（第5ラウンド最初の判断前）、最終ラウンド中は13〜14。ラウンド途中のgame_scoresは直前の確定ラウンドまでの累積得点なので、11と12を区別する。

配札ID、実配札Hash、観測Hash、局面Hash、収集元、席、turn、ラウンド、seed区分を保存する。実配札Hashは識別用で、手札内容を戦略に渡す用途ではない。観測Hashは観測全体、局面Hashは観測Hashとルール版から計算する。同じ局面は一つにまとめ、originsにすべての収集元を残す。

分析枠には均衡・上側接近・下側接近を巡回し、使用済み配札数・収集元数が少ないものを優先する。同数ならturn 12→11→13→14→9→6→3などの固定順、収集元・席・Hash順で決める。対照枠は最高→最低→同点を巡回する。これは結果を見ない選抜であるが、無作為標本ではない。厳密中間が枠に足りない場合は残りを対照で埋める。空の層を人工局面で補わない。

## 合法手の反実仮想比較

選抜した局面の全合法手を既存 `rollout_trial` で比較する。入力は本人の不完全情報Observationのみ。実際の相手手札・余り札は参照せず、UniformSamplerで未公開札を割り当てる。本人の手札、公開履歴、残り枚数は維持する。相手の行動傾向を条件とするベイズ推定は未対応。

同一試行番号では同じサンプル世界、席別の同じ乱数初期状態を各候補で共有する。継続戦略は複製し、各席自身の観測だけを渡す。候補順によって標本が変わらないことをテストした。分岐後の乱数消費・ゲーム進行まで同一とは限らない。

既定継続は全席Random。7種類の軽量戦略から席別に設定でき、探索戦略の再帰呼び出しは拒否する。継続条件の違う結果を合算しない。

各札について自己・相手A・相手Bの直近2位確率、当該ラウンド終了時のカード得点の平均、次境界の累積得点分布、最終ラウンド開始の厳密中間確率、最終報酬、単独勝者率、同点を含む勝者率、上下差・相手間差の変化、時間を記録する。A/Bは自分以外の席番号順。確率3つの合計は1である。

「次境界」は現在のラウンド終了直後で、最終ラウンドでは終局境界。turn≥12では最終ラウンド開始の中間確率をnull（適用対象外）にする。上下差変化は初期から終局までの符号付き差で、終局に中間でなくなる場合もある。上差変化＋下差変化＝相手間得点差変化を検証している。

自分の2位確率低下だけを「特定相手へ譲った」と呼ばない。相手ごとの確率と、候補間の対応差を別々に保存する。

## ケースBの操作的定義

候補Aに対して候補Bを比較する。

| 条件 | 判定 |
| --- | --- |
| G1 | Bの自己直近2位率が低く、Bの最終期待報酬が高い |
| G2 | Bで初期状態から相手間得点差が正に拡大し、拡大量もAより大きい |
| G3 | 初期状態が厳密中間で、Bの次境界の厳密中間確率がAより高い |
| G4 | Bの最終期待報酬がAより高い |
| ケースB候補 | 同一局面・同一向きの比較でG1〜G4がすべて成立 |

G3は「途中ずっと中間を保つ確率」ではなく、次境界で中間になる確率。G4はG1の報酬条件と重なるが別欄で記録する。点推定の同時成立は因果機序の証拠ではない。

探索順で最初のG1ペアを、上限件数まで検証する。ケースBに限って選ぶ方式ではない。検証世界は開発世界と別seedで作り、札の組と向きを固定して再評価する。方向再現、探索時ケースB、検証時ケースB、両段階のケースB再現を区別する。検証時に初めてケースBになっても「ケースB再現」とは表示しない。

## 統計とseed管理

開発配札は0〜999999、検証系列は1000000+validation_offset。最終評価seedは使わない。既存Arenaのdeal_seeds、Designの予約、Middleの予約との衝突を拒否する。policy_seedと局面Hashから開発・検証の別名前空間で世界seedを導出する。

候補報酬と対応差は固定標本Hoeffding境界＋Bonferroni。探索familyは `max_positions × (17 + 272 × 7)`、検証familyは `max_validate × 16` の上限で補正する。方向付き全比較を含む保守的な設定である。報酬の絶対上限2、報酬差4、確率差1、得点差変化195、候補間得点差変化390を使用する。得点差の境界は意図的に緩く、少数世界で区間が狭くならない。

同じ試行の候補差から区間を計算し、独立区間を引き算しない。不確実性が十分に小さいという表示は、直近率差・報酬差・相手差の候補間差・初期からの正の拡大・中間維持差の区間下限がすべて0より大きい場合だけ。確証的な採用判定は行わない。

世界標本数は実配札数ではない。層別集約は同一配札内の分析局面を平均し、配札を等重みで集約する。表示するのは「逆転／ケースBが一つ以上ある選抜済み局面の割合」で、母集団での発生率や平均因果効果ではない。少数配札のため、配札間の一般化区間や層の優劣は提示しない。

停止・時間切れでは完了扱いにせず、完了した局面だけを保存する。途中停止の結果を固定標本の確証として解釈しない。単一Labワーカー、8配札・24分析局面・64探索世界・128検証世界・10000派生対局・120秒が上限。実行前に未校正の上側時間見積もりも確認する。

## 制限と次の課題

- 4独立配札・8探索世界・32検証世界は少なく、候補選択の不安定性が大きい。世界追加は新しい独立配札の代わりにならない。
- 事前選抜は時点・配札・収集元を均す方式で、確率標本ではない。すべての層・時点に分析枠を保証しない。
- 検証対象をG1順で選ぶため、今回のケースB探索候補12ペアを直接追試していない。次はケースB選抜を明示した別計画が必要。
- G3の時点定義、正の得点差拡大条件、緩い区間を変える場合は新しい条件として事前登録する。
- サンプリングは公開情報に矛盾しない一様割当。相手の政策・カード選好の推定を含まない。
- 世界seedの分離は同じ局面の再評価であり、別配札による一般化検証ではない。相手構成・継続戦略の変更、別配札追試が必要。
- 進捗は処理ブロック数で、正確な残り時間ではない。停止は協調式、実行中の局面は未完のまま破棄する。
- 履歴一覧は結果全体を返すため、大規模な蓄積では一覧の軽量化が必要。
- 条件の同時成立から因果機序を断定できない。上側／下側相手を明示する追加介入と、探索から独立した配札での検証を次の課題とする。
