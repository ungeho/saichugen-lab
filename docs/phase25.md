# Phase 25：Evidence Accumulation Lab

## 目的と既存基盤の再利用

Phase 24の基準コミットは `b5491d17efdd95d46351c6a4c502262529d442a1`。ゲーム・戦略・終局報酬は変更しない。既存Design Labの事前登録、進捗・取消、実行予算、Evaluation Labの配札単位対応差、Hoeffding＋Bonferroni、必要数設計を利用する。Evidence Labは完了結果を参照する層であり、実験を直接実行しない。

## Evidence Series

ID・版、仮説、探索的／確証的区分、最小効果、残り秒、他の未検証仮説数を保存する。同じID・版は上書きできない。関連付けにはPlan ID・版・Hashまたは過去Evaluation IDを指定する。各追記は実験ID、日時（過去データにない場合は不明）、seed区分、条件signature、実装hash、戦略定義・相手構成、報酬差、対局数、時間、元結果hashを保持する。推薦理由・根拠も追記時点のスナップショットとして保存する。

SQLiteには新しいevidence_series、evidence_entries、evidence_recommendationsテーブルをCREATE IF NOT EXISTSで追加する。既存experimentsは変更しない。Seriesと証拠のhash・元結果hashを読込時に照合し、不一致はInvalidated。DB管理者による改ざん防止や暗号署名ではない。

## 比較可能性と重複

ルール・終局報酬版、戦略定義・パラメータ、相手構成、6役割順、方策seedと生成方式、情報条件、seed区分、統計実装、alpha・family・集約法・事前重みを照合する。配札数・offset・実行時間の相違は追加実験として許す。条件不一致は拒否する。異なる構成名も区別する保守的な方式。

配札IDは実際の3手札と余りカードの並びのSHA-256。現在と同じgame/cards.py実装hashの場合だけseedから再構成する。元の手札内容はEvidenceへ保存しない。生成方式が変わった場合は、seedだけで同一性を断定せず取込を拒否する。構成間で共有する配札は許し、実験をまたぐ重複は全構成の和集合で拒否する。SQLite書込ロック取得後も再検査する。再実行・再追加では標本数が増えない。

## 統計と順序

各構成・対象戦略について全6役割順の平均報酬差を独立配札単位として蓄積する。実験の関連付け順→各Planの登録配札順を記録し、結果に応じた並べ替えは行わない。累積平均、標本SD、直前からの平均変化、時間、診断区間を表示する。10配札未満は区間なし。分散0でもHoeffding区間は0幅にならない。

構成間効果差は、共有した同じ配札のD(構成2)−D(構成1)から計算する。構成数や6席順を独立配札数に加算しない。共有配札で事前の統合重みがある場合だけ加重統合曲線を提供する。別配札方式の統合曲線は未対応。

**収束グラフの途中区間は逐次判定の保証がない。** 区間を繰り返し見て採用・棄却しない。探索的な事後統合は確証評価へ昇格しない。確証Seriesは単一の完了確証Planだけを保持し、既存Planの最終分析を併記する。複数確証実験の合算は未対応。

## 次の実験と計算予算

必要数は既存の設計支援を使い、10配札未満・分散0・分散不明では追加パイロットを推奨する。十分な標本なら最小効果と分散から正規近似の必要数、保守的必要数と費用を示す。予算不足は再検討し、他に未検証仮説があればそちらを優先する案を出す。これは弱さの証明ではない。相手構成が1種類なら追加構成を推奨する。検証用配札での再現性は今回未確認として明示する。

追加配札数×構成数×戦略設定数×6で対局数を見積もる。1配札の時間単位は1構成・全設定・全6役割順。現在SDを将来へ外挿した補正前正規近似の幅は診断専用。10配札未満や分散0では幅を予測しない。将来の平均・勝敗を予測するものではない。

推薦から生成するのは、既存Design Labの安全な次版Draftのみ。登録・実行は別操作。確証評価を自動開始しない。

## UI・API・CLI

「Evidence Accumulation Lab」でSeries作成、一覧、Plan関連付け、条件と履歴、構成別・構成間・統合の収束グラフ、時間・SD・配札順、追加予算シミュレーション、推薦、JSON保存を利用する。実験実行・進捗・停止はExperimental Design Labで操作する。

APIは `/api/evidence/series`、`/{id}/{version}`、`/entries`、`/projection`、`/draft`、`/export`。CLIはPYTHONPATH=backend/srcを設定し `python -m strategy_arena.experiments.evidence_cli --database research-local/phase25/results.sqlite --series adaptive-b-evidence --create <Series JSON> --source <参照JSON> --output <結果JSON>`。既存Seriesでは--createを省略する。--additional-dealsで費用を出せる。CLIは対局しない。
