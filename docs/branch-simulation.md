# 分岐シミュレーション

比較画面の現在局面・履歴局面から、候補カードを最初の一手として残りを対戦する機能です。実対戦の手札・戦略・乱数を変更しません。

## 使い方

「同じ局面でAIを比較」で局面を選び、比較すると選択カードが分岐候補の初期値になります。手札から任意の候補も選べます。各席の継続戦略、試行回数、整数シードを設定して「分岐シミュレーションを実行」を押します。同じカードは、同じ継続設定の実験内で重複計算しません。異なる継続設定は別の実験です。

全席の継続戦略は登録ファクトリの初期状態を複製します。学習済み設定がファクトリに含まれる場合はそれを維持します。実対戦中の私的な内部状態は引き継ぎません。対象席の最初の手は強制適用し、その手番では対象戦略を呼びません。相手2席は同じ選択直前の観測から選び、次の手番から全席が指定戦略を使います。詳細判断ログは生成しません。

## 不完全情報と世界の生成

APIはゲームのロック内で既存の局面取得処理を使い、対象席のObservationと公開局面情報だけを切り出します。その後のワーカーには実対戦のGame、完全リプレイ、相手の内部状態を渡しません。他席視点は既存と同様、終局後に分析表示を開いた場合のみ利用できます。

既存のUniformSamplerを使い、自分の残り手札と公開済みカードを除いた全カードをシャッフルし、相手の残り枚数と未使用1枚に一様に配分します。過去の行動の好みを推測する事後分布ではありません。各席の公開済みカードを残り手札に戻して17枚の初期配札を再構築し、公開履歴を再生します。履歴の得点と復元後の対象観測の一致を検証します。

サンプリングした世界の各席には、その席の手札・公開履歴・得点だけを持つ通常のObservationを渡します。サンプリングした他席の手札や未使用カードはAPI結果に含めません。

## 共通条件と再現性

同じ試行番号では同じサンプリング世界を全候補で共有し、席別の初期乱数状態も共有します。世界用・席別戦略用シードは実験シードと試行番号から独立に導出し、候補の並びに依存させません。分岐後の手札や戦略の乱数消費順序は変化するため、共通乱数はばらつきの除去を保証しません。

結果には局面IDと観測、ルール版、情報条件、シード、試行回数、カード、継続戦略名・版、初期状態方針、サンプラー版を保持します。同じコード・Python環境・これらの条件と、再現可能な登録ファクトリを使う場合に統計結果が再現します。外部乱数・時刻・外部サービスに依存する戦略は保証対象外です。判断時間は対象外です。

## 統計の意味

勝者は既存エンジンの最終中間得点の全プレイヤーです。同点時に勝利を分割しません。勝率の95%区間にはWilson区間を使用します。平均得点と得点の母標準偏差を表示します。得点の高い順の順位を集計し、同点は占有順位範囲（例: 1–2位）として表示します。このため「2位」の回数と勝利数は同義ではありません。

候補間の差は共通試行の勝利指標差と最終得点差の平均です。勝率差の区間は対応差の標準誤差を使う正規近似（1試行では未提供）です。少数試行や全差が同じ標本では過信できません。100試行未満では画面に注意を表示します。全区間は一様サンプリングと継続戦略を仮定した推定誤差で、モデルの誤りを表しません。

## 実行管理・API

- POST /api/games/{id}/branches: 局面、カード、3席のstrategies、trials、seedを指定。202でジョブを返します。
- GET /api/branches/{id}: 状態・完了試行数・結果を取得。
- POST /api/branches/{id}/cancel: 停止要求。
- 同時実行1件。試行1〜1000回、候補最大17枚、重複除去後の候補数×試行数は10000以下。
- 制限時間60秒。停止要求・時間制限は戦略呼び出しの前後と手番境界で確認。終了しない外部戦略の呼び出しを強制中断する機構はありません。その場合ワーカーは占有されたままになるためサーバーを再起動してください。
- 成功以外は部分統計を公開しません。失敗時も元の対戦に影響しません。
- 最新20件をメモリ保持。サーバー終了時に停止要求を出します。永続保存・ページ再読込からのジョブ復帰は未対応です。
- 局面変更・パネルを閉じる操作ではジョブの停止を要求します。

単一ローカルワーカーのため重い計算はCPUを共有します。完全情報、行動に基づく重み付きサンプラー、継続状態の明示的スナップショット、SQLite保存は将来の拡張候補です。


## 終局報酬の追加

累計・勝者判定後に2003年表2の報酬を共通関数で計算します。候補ごとに平均終局報酬・単独/共同勝利率を表示し、グラフは勝率と平均終局報酬を切り替えられます。候補対の報酬差は同じ試行の差から平均と正規近似95%区間を求め、1試行は区間未提供、分散0は明示します。既存の累計得点差・勝率差・停止制限は維持。結果schema_version=2と報酬版を記録します。詳しくは[終局報酬設計](terminal-rewards.md)。
