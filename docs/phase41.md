## 4. 事前採用基準と不確実性

主評価は配札等重みの対応wall差と対応終局報酬差。負のwall差が時間節約、正の報酬差がFixedより高い独立推定報酬。報酬差の符号許容誤差は0。補助指標を重み付き主スコアへ混ぜない。

採用判断に最低20独立配札を要求する。20未満は「現時点では採用根拠不足」。20以上では、wall差の探索的95%区間上限<0かつ報酬差区間下限>=−0.05を条件付き採用候補とし、他は継続検証とする。Fixedは比較基準。実戦採用の自動反映はしない。今回5配札の結果が良くても基準を後から緩めない。

配札の対応差を2000回percentile bootstrapで再標本化し、95%区間を記述する。専用seed41001と比較名から導出する。反復→局面内モデル→局面→配札の各段階で等重みとする。同じ配札をモデル数や局面数だけ複製しない。独立配札数が小さく、区間は不安定。全差0の退化区間は同等性の証明ではない。層別・複数比較は探索的で多重比較補正済みの確証区間ではない。
